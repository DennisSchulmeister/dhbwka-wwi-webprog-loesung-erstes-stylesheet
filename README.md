# Webprogrammierung / Lösung / Erstes Stylesheet

Dies ist die **Musterlösung** zur Aufgabe „Erstes Stylesheet" aus der Vorlesung **Webprogrammierung** (Wirtschaftsinformatik, DHBW Karlsruhe), Kategorie *HTML und CSS*.

Eine erste eigene HTML-Seite wird mit einem externen CSS-Stylesheet formatiert.

Dieses Repository ist Teil der Quellcodes [dhbwka-wwi-webprog-quellcodes](https://github.com/DennisSchulmeister/dhbwka-wwi-webprog-quellcodes) zur Vorlesung Webprogrammierung.
